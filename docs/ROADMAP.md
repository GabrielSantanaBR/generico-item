# Roadmap

## Demo pública — concluída

- [x] Dashboard operacional
- [x] Agenda e status de atendimentos
- [x] Cadastro de clientes
- [x] Cadastro de serviços
- [x] Orçamentos
- [x] Modelos de mensagem
- [x] Atalho para WhatsApp
- [x] Página pública de agendamento
- [x] Persistência da demonstração no navegador
- [x] Exportação e importação de backup
- [x] Layout mobile
- [x] PWA
- [x] GitHub Pages e checks estáticos

## Versão comercial — núcleo

- [ ] Backend e PostgreSQL
- [ ] Autenticação e recuperação de acesso
- [ ] Perfis de administrador e equipe
- [ ] Agenda por profissional
- [ ] Regras de disponibilidade e bloqueio
- [ ] Histórico persistente do cliente
- [ ] Dashboard por período
- [ ] Logs e backup

## Automação

- [ ] Integração oficial com WhatsApp
- [ ] Confirmação e lembrete de agendamento
- [ ] Follow-up de orçamento
- [ ] Link de reagendamento/cancelamento
- [ ] Integração com Google Calendar

## Receita adicional para o cliente

- [ ] PIX/sinal de reserva
- [ ] Pacotes e recorrência
- [ ] Cupons ou campanhas
- [ ] Relatório de retorno e ticket médio
- [ ] Comissão por profissional

O roadmap é modular: uma adaptação comercial não precisa contratar todas as etapas. O escopo deve acompanhar o problema real do negócio.
